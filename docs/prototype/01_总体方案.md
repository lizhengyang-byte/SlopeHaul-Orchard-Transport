# 整机样机 SlopeHaul-P1 · 总体方案

面向山地丘陵果园采收后运输：坡度变化大、行间窄（1.4–2.0 m）、地面松软、路面起伏。目标不是再做一个遥控运输车，而是把「地形感知 → 滑移/姿态估计 → 自适应行走 → 失效安全」这条闭环装到一台能下地的整机样机上。

## 1. 整机定义

| 项目 | 指标 | 依据 |
|---|---|---|
| 外形尺寸（长×宽×高） | 1620 × 1100 × 920 mm（不含传感器杆） | 果园行距 ≥1.4 m，宽度留 300 mm 余量 |
| 轴距 / 轮距 | 1250 / 1100 mm | 与仿真模型一致，便于算法直接迁移 |
| 轮径 / 离地间隙 | 480 / 260 mm | 越障 0.16 m 台阶，跨垄沟不托底 |
| 整备质量 / 额定载重 | 320 / 200 kg（最大 250 kg） | 对标 Agrofelis 250 kg 级 |
| 行走机构 | 4×4 轮毂电机 + 前后两组被动摆动桥（摆角 ±12°） | 兼顾窄行通过性与起伏地形四轮接地 |
| 转向 | 电子差速（skid-steer），最小转弯半径 ≤1.1 m | 窄行掉头 |
| 爬坡能力 | 干硬土 25°、松软土 20°、湿滑（μ0.45）18° 以内；超过则拒行 | 牵引/附着核算见 02 |
| 侧倾极限 | 静态 42.5°，动态包络 31.9°（0.75 倍裕度） | `atan(track/2h)` |
| 速度 | 0.2–1.35 m/s（坡上自动降到 0.85 m/s 以下） | 仿真标定 |
| 续航 | 满载 20° 松软坡约 3.8 km/次；平地约 6.5 km/次 | 2.4 kWh 电池取 80% 可用，按 0.505 / 0.294 Wh·m⁻¹ |
| 制动 | 液压盘刹（前）+ 电磁失电弹簧制动（后），18° 坡驻车零溜坡 | 见 02 制动核算 |
| 防护 | IP54，工作温度 −5~45 ℃ | 果园露地作业 |

## 2. 系统分层

```
        ┌──────────── 任务层（2 Hz）────────────┐
        │ 作业路线 / 装卸点 / 电量与换电调度      │
        └───────────────┬──────────────────────┘
    ┌───────────────────▼────────────────────┐
    │ 感知 10 Hz：2.5D 代价层（0.15 m，34×24）│ ← D435i×2、LiDAR、双 IMU
    │ 土壤分类 2 Hz：纹理 → μ/crr 先验         │
    ├────────────────────────────────────────┤
    │ 估计 200/50 Hz：速度 EKF、附着 RLS、滑移 │ ← 编码器、IMU、称重
    │ 载荷/质心 20 Hz                          │
    ├────────────────────────────────────────┤
    │ 决策 100 Hz：速度规划 + CoM 横向规划 0.5 Hz│
    │ 自适应控制：坡度前馈 + 速度 PI + 滑移 PI  │
    │ 驻车状态机 + 稳定包络                     │
    ├────────────────────────────────────────┤
    │ 失效安全 20 Hz：OK→DERATE→HOLD→STOP 阶梯 │ ← 心跳、围栏、急停、温度
    └───────────────┬────────────────────────┘
                    ▼ CAN / UART
        ┌───────────────────────────┐
        │ 实时层 STM32H7 1 kHz       │ 电机 FOC 环、制动、看门狗
        └───────────────────────────┘
```

## 3. 与开源样机的取舍（逐项写清“取了什么、没取什么”）

| 参考 | 取 | 不取 / 改造 | 原因 |
|---|---|---|---|
| **Agrofelis**（MIT，4WD 轮毂电机，250 kg，30% 爬坡） | 载重/坡度/制动指标作为验收基线；“AI-ready”计算+实时节点双脑架构 | 无悬挂、785×992 焊接车架 | 我们要窄行（宽 1.1 m）+ 起伏路面四轮接地，必须有摆动桥；车架改铝型材+局部焊接便于迭代 |
| **AgriCruiser**（GPL v3，开源 CAD+BOM） | 只借鉴“可重构 T-slot 车架 + 编码器闭环 + 24/48V 锂电”的工程做法 | 不复制任何文件 | GPL v3 有传染性，且两轮驱动在松软坡上附着不足 |
| **AgriBot / PRBonn**（无 LICENSE） | 只参考其 ROS 节点划分（定位/导航/底盘分层） | 不引用代码与图纸 | 仓库未声明许可，默认保留全部权利 |
| **Papaya Pathfinder**（Apache-2.0，六轮 rocker-bogie，3D 打印） | 摇臂被动适应地形的机构原理 | 不做六轮、不做全 3D 打印 | 六轮在 1.1 m 宽行间转向半径过大；承重件需金属 |
| **ArduRover** | 失效安全分层语义（围栏、心跳、急停、过温降载） | 不移植固件 | 我们自研 STM32 实时层 + Python 决策层，接口按 ArduRover 语义对齐便于日后替换 |
| **terrain_aware_navigation / costmap 插件** | 2.5D 高程 + 自定义代价图层 + 台阶坡度校正 | 不上 ROS 2 全栈 | 样机阶段先保证算法可复现；接口预留为 Nav2 CostmapLayer |
| **Agronav / botanbot_sim / orchard_simulation** | 行内语义导航、Ackermann+2.5D 导航的工程经验 | 不搭 Gazebo 仿真 | 已有纯 Python 闭环仿真，实机标定优先 |

## 4. 三处“必须自己解决”的差异点

1. **重载重心变化**：货箱满载使质心从 0.52 m 升到 0.60 m，侧倾包络收紧 4.7°；样机用 4 点称重实时估计载荷与横向偏载，超 15% 偏载即降速。
2. **驻车能力可判定**：18° 湿滑坡上“能不能停住”由 `min(制动能力, 静摩擦能力)` 与下滑分力比较后决定，不足则拒绝释放制动并上报 slipping，而不是赌一把。
3. **拒行边界**：26° 湿滑坡是物理不可通行，样机的正确行为是**停在坡脚**并给操作员明确原因，而不是“闯一下就知道了”。
