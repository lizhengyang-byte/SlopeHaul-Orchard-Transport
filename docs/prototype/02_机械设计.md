# 02 · 机械设计

所有能力都给核算过程，不写“能爬 30°”这种没有依据的数字。质量口径：整备 320 kg + 满载 200 kg = 520 kg，总重 W = 520×9.81 ≈ 5.10 kN。

## 1. 总体布置

- 车架：40×40 铝型材主梁（6061-T6）+ 关键受力节点 Q345 焊接加强块，整体尺寸 1620×1100 mm，双层结构：下层电池与电控（离地 260 mm），上层货箱。
- 行走：前后两组**被动摆动桥**（每组 2 轮，绕车架横轴摆动 ±12°，无动力输出），四轮各自独立轮毂电机驱动。摆动桥解决“起伏路面四轮同时接地”，比刚性桥少一轮悬空，比六轮摇臂转向更紧凑。
- 货箱：1050×850×280 mm，底板 2 mm 花纹铝板，四角 4 点称重；侧板可拆，方便叉筐直接装卸。
- 质心：空载 (x, y, z) ≈ (0.62, 0.00, 0.52) m；满载（货物均布）≈ (0.66, 0.00, 0.60) m；偏载 15% 时横向质心偏移 0.09 m。

## 2. 轮系与传动

| 项 | 值 | 说明 |
|---|---|---|
| 轮胎 | 4.00-8 充气草地胎，外径 480 mm，宽 120 mm | 松软地面接地压力低，滚阻可接受 |
| 轮毂电机 | 4× 48 V 永磁同步，额定 400 W / 峰值 800 W，峰值转矩 190 N·m，内置霍尔 | 直驱，无减速箱，效率 88% |
| 轮端牵引力 | 4×190/0.24 = 3167 N | 力矩能力上限 |
| 平地阻力 | crr 0.03 → 153 N；20° 松软坡 → 2.21 kN | 详见下表 |

## 3. 爬坡能力：力矩够 ≠ 爬得上去

真正限制是附着，不是电机。设四轮驱动、附着系数 μ、滚阻 crr：

\[
F_{\text{need}} = W(\sin\theta + c_{rr}\cos\theta),\qquad F_{\max} = \mu W \cos\theta
\]

解得 \(\tan\theta_{\max} = \mu - c_{rr}\)：

| 地面 | μ | crr | 附着允许坡度 | 力矩是否够（3167 N） | 结论 |
|---|---|---|---|---|---|
| 干硬土 | 0.80 | 0.030 | 37.4°（限 30°） | 30° 需 2.72 kN，够 | 标 25° 留裕度 |
| 松软土 | 0.62 | 0.095 | 27.7° | 20° 需 2.21 kN，够 | 标 20° |
| 湿滑黏土 | 0.45 | 0.080 | 19.6° | 18° 需 1.81 kN，够 | 标 18°，26° 直接拒行 |

所以“爬坡 30%”这类宣传对 250 kg 级车没有意义：湿滑土上 20° 就已经贴着附着极限。样机的做法是在代价层里用 `atan(0.85μ)` 做硬判据，超过就拒绕起步。

## 4. 侧倾与俯仰

\[
\theta_{\text{roll}} = \arctan\frac{B/2}{h},\qquad \theta_{\text{pitch}} = \arctan\frac{L_{\text{wb}}/2}{h}
\]

- 空载（h=0.52）：侧倾 46.6°，俯仰 50.3°；
- 满载（h=0.60）：侧倾 **42.5°**，俯仰 46.1°；
- 动态包络取 0.75 倍：满负载时 **31.9°**，与 Agrofelis 公布的最大侧倾 32° 同级。

横坡工况验收取 14°（S2 场景），工作点距包络还有 18° 裕度；偏载 15% 时侧倾角降到 38.8°，仍高于验收线。

## 5. 制动与驻车

| 项 | 值 | 核算 |
|---|---|---|
| 前轮液压盘刹 | 2×160 N·m | 轮端制动力 2×160/0.24 = 1333 N |
| 后轮电磁失电弹簗制动 | 2×160 N·m（断电自动夹紧） | 1333 N，断电即驻车（fail-safe） |
| 总制动力 | 2667 N | 相当于 \(\tan\theta\) = 0.523 → **27.6°** 静态可驻 |
| 18° 湿滑坡 | 下滑分力 1.61 kN | 制动 2.67 kN > 1.61 kN，余量 66% |
| 26° 湿滑坡 | 下滑分力 2.24 kN | 制动够但**附着不够**（μWcosθ=2.06 kN < 2.24 kN）→ 判定不可通行 |

注意最后一行：制动器够、轮胎不够，这才是“停车困难”的真实成因。控制上表现为驻车状态机比较 `min(制动能力, 静摩擦能力)` 与下滑分力，不足则不释放制动并累计滑距。

制动距离（0.85 m/s、18° 干硬土）：
\[
a = g(\mu\cos\theta - \sin\theta) - c_{rr}g\cos\theta = 2.75\ \text{m/s}^2,\quad d = v^2/2a = 0.13\ \text{m}
\]
加 0.3 s 响应迟滞后约 **0.4 m**，验收线取 ≤0.6 m。

## 6. 结构校核要点

- 单轮静载 1.28 kN；动载系数取 1.8（越障冲击）→ 按 2.3 kN 设计轮轴与摆臂铰点，Q345 铰点轴 φ30 mm，安全系数 >2。
- 货箱满载 200 kg 均布 → 底板面载 0.22 kPa，2 mm 花纹板跨距 400 mm 时挠度 <1.5 mm。
- 摆动桥摆角 ±12° 时限位块承受侧向力按 1.5 kN 设计；铰点用自润滑铜套，免维护。
- 电池仓独立下挂，重心尽量低；4 点称重传感器量程 0–150 kg/点（合计 600 kg，覆盖 1.15 倍超载）。

## 7. 与仿真模型的对应关系（保证算法可直接迁移）

| 仿真参数 | 样机取值 |

| 单轮峰值转矩 190 N·m / 制动 120 N·m | 电机 190 N·m / 制动 160 N·m（更保守：仿真低估了制动力） |
| 质心高 0.52→0.60 m | 同 |
| crr 0.030（硬）/ 0.095（软） | 轮胎实测标定后回填 |
| 倾翻判据 atan(track/2h) | 同 |

差异只留在“制动更强”这一侧，属安全方向，不需要重跑基准；标定后把实测 μ/crr 写回 `config.py` 再复跑一次即可对齐。
