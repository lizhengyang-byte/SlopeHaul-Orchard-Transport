# SlopeHaul-P1 整机样机方案（汇总）

本文是整机样机的仓库侧汇总（分册《总体/机械/电气BOM/控制软件/装配试验》同步归档在飞书项目文件夹）。所有能力都附核算过程。

## 1. 整机定义

| 项 | 指标 |
|---|---|
| 外形 | 1620×1100×920 mm（不含传感器杆） |
| 轴距/轮距/轮径 | 1250 / 1100 / 480 mm，离地 260 mm |
| 整备/额定载重 | 320 / 200 kg（最大 250 kg） |
| 行走 | 4×4 48V 轮毂电机 + 前后两组被动摆动桥（摆角 ±12°） |
| 转向 | 电子差速 skid-steer，最小转弯半径 ≤1.1 m |
| 爬坡 | 干硬 25° / 松软 20° / 湿滑(μ0.45) 18°；超过即拒行 |
| 侧倾 | 静塲 42.5°，动态包络 31.9°（满载、0.75 裕度） |
| 续航 | 2.4 kWh 电池，满载 20° 坡约 3.8 km；平地约 6.5 km |
| 制动 | 前液压盘刹 2×160 N·m + 后电磁失电制动 2×160 N·m（断电即驻） |

## 2. 机械核算

爬坡受限于**附着**而不是电机：\(\tan\theta_{\max}=\mu-c_{rr}\)。

| 地面 | μ | crr | 附着允许 | 矩矩能力 3167 N |
|---|---|---|---|---|
| 干硬土 | 0.80 | 0.030 | 37.4° | 30° 需 2.72 kN，够 |
| 松软土 | 0.62 | 0.095 | 27.7° | 20° 需 2.21 kN，够 |
| 湿滑黏土 | 0.45 | 0.080 | 19.6° | 18° 需 1.81 kN，够 |

侧倾：满载 h=0.60 m → atan(0.55/0.60)=42.5°，0.75 裕度后 31.9°（与 Agrofelis 公布 32° 同级）。

制动：总制动力 2667 N → 静态可驻 27.6°；但 26° 湿滑坡下滑分力 2.24 kN 已超过附着能力（μWcosθ=2.06 kN），制动器够、轮胎不够——这才是“停车困难”的真因。18° 湿滑只需 1.61 kN，余量 66%。制动距离（0.85 m/s、18°）=0.13 m，加 0.3 s 响应迟滞约 0.4 m。

功率核算：满载 20° 松软坡 F×v = 2.21 kN×0.85 = 1.88 kW → 48V 下 39A，1C 以内安全；可用能量 2.4kWh×80%=1.92kWh，按 0.505 Wh/m 得 3.8 km。

## 4. 控制分层与节点

```
任务层 2Hz → 感知 10Hz（代价层 0.15m）→ 估计 200/50Hz → 决策 100Hz + 规划 0.5Hz
           → 失效安全 20Hz（OK/DERATE/HOLD/STOP）→ H7 实时 1kHz（FOC、制动、看门狗）
```

| 节点 | 频率 | 对应代码 |
|---|---|---|
| perception_costmap | 10 Hz | `perception/costmap.py` |
| soil_classifier | 2 Hz | `perception/soil_classifier.py` |
| state_estimator | 200/50 Hz | `estimation/{slip,load}.py` |
| slip_model | 20 Hz | `estimation/load_slip.py` |
| path_planner | 0.5 Hz | `planning/lateral_planner.py` |
| drivetrain_ctrl | 100 Hz | `control/{adaptive,stability}.py` |
| hill_hold | 50 Hz | `control/hillhold.py` |
| failsafe | 20 Hz | `control/failsafe.py` |
| motor_loop | 1 kHz | 驱动器 FOC |

安全原则：急停、过温、心跳、驻车释放必须在 H7 本地有独立判据，上层死机时下层能自己停住。

## 6. 与开源样机的取舍

| 参考 | 取 | 为什么改 |
|---|---|---|
| Agrofelis (MIT, 250kg) | 载重/坡度/制动指标基线；双脑架构 | 无悬挂、车宽 992mm 不适合窄行，改摆动桥+1100mm 宽 |
| AgriCruiser (GPLv3) | T-slot 可重构车架、编码器闭环思路 | GPL 传染性，不复制文件；两轮驱动附着不足 |
| AgriBot (无 LICENSE) | 仅参考 ROS 节点划分 | 未声明许可，代码/图纸一律不引用 |
| Papaya Pathfinder (Apache-2.0) | 摇臂被动适应地形原理 | 六轮转向半径过大，承重件需金属 |
| ArduRover | 失效安全分层语义（围栏/心跳/急停/过温） | 不移植固件，自研 H7 层，接口语义对齐 |
| terrain_aware_navigation | 2.5D 高程 + 自定义代价图层 + 台阶坡度校正 | 不上 ROS2 全栈，保留可复现性；接口预留 Nav2 插件 |

## 7. 交付物

- 机械：车架/摆动桥/货箱图纸（含公差）、装配 BOM（`bom_slopehaul_p1.csv`）；
- 电气：主回路/信号/CAN 原理图、线束表、接插件定义；
- 软件：Jetson 镜像（含本仓库算法）、H7 固件、参数文件、标定记录表；
- 文档：飞书项目文件夹内 5 册分文档 + 本文 + 布局图 `figures/prototype_layout.png`。

真正卡进度的不是算法，而是轮毂电机与驱动器匹配、制动/驻车机械可靠性、称重标定这三件“看起来最简单”的事。
