# 04 · 控制与软件（算法如何装到样机上）

仿真里的策略不是纸面结论，本文把它拆成可部署的节点、频率与接口，并说明每个模块在实机上最容易坏在哪里。

## 1. 节点拓扑

| 节点 | 平台 | 频率 | 输入 | 输出 | 对应代码 |
|---|---|---|---|---|---|
| `perception_costmap` | Jetson | 10 Hz | 前后深度图、LiDAR、IMU 姿态 | 2.5D 代价层（0.15 m）、blocked/v_limit | `perception/costmap.py`、`elevation.py` |
| `soil_classifier` | Jetson | 2 Hz | 32×32 纹理、坡度、粗糙度 | μ/crr 先验、类别置信度 | `perception/soil_classifier.py` |
| `state_estimator` | Jetson | 200/50 Hz | 编码器、IMU、称重 | 速度、附着 μ、滑移率、载荷/质心 | `estimation/{slip,load}.py` |
| `slip_model` | Jetson | 20 Hz | 坡度、速度、μ | 滑移预测、坡度灵敏度 | `estimation/load_slip.py` |
| `path_planner` | Jetson | 0.5 Hz（增量 2 Hz） | 代价层 | 横向偏移序列、可行性 | `planning/lateral_planner.py` |
| `speed_planner` | Jetson | 100 Hz | 代价层、姿态、载荷 | 目标速度、限速原因 | `control/adaptive.py` |
| `drivetrain_ctrl` | Jetson → H7 | 100 Hz | 目标速度、滑移 | 四轮转矩指令、制动 | `control/adaptive.py`、`stability.py` |
| `hill_hold` | Jetson → H7 | 50 Hz | 坡度、μ、制动能力 | 驻车状态、释放许可 | `control/hillhold.py` |
| `failsafe` | Jetson + H7 | 20 Hz | 心跳、围栏、姿态、温度、急停 | OK/DERATE/HOLD/STOP | `control/failsafe.py` |
| `motor_loop` | 驱动器 | 1 kHz（FOC 内部 20 kHz） | 转矩/转速指令 | 电流环 | 驱动器固件 |

分工原则：**安全相关（急停、过温、心跳、驻车释放）在 H7 上必须有独立的本地判据**，不能只依赖 Jetson——上层死机时下层要能自己停住。这也是 ArduRover 的 fail-safe 语义：保护逻辑下沉，决策逻辑上浮。

## 2. 关键接口（字段即契约）

```
# Jetson → H7 @100 Hz
cmd { t_cmd[4]  : N·m，逐轮，负值为回馈
      brake[4]  : 0..1，占空比
      hold      : bool，请求驻车
      enable    : bool，驱动器使能
      seq       : uint16，丢包检测 }

# H7 → Jetson @100 Hz
state { v_wheel[4], temp_motor[4], soc, estop, heartbeat_ok, fault_code }

# H7 本地保护（不依赖上层）
- 心跳 >0.6 s 未更新 → 转矩斜坡归零 + 弹簧制动夹紧
- 任一电机 >90 ℃ → 该轮限扭 50%，>100 ℃ 断使能
- 倾角 >35°（本地 IMU 双路一致）→ 停车
```

## 3. 参数表（从 `config.py` 直接搬到实机）

| 参数 | 值 | 实机注意点 |
|---|---|---|
| 控制周期 | 0.02 s（50 Hz 决策，100 Hz 输出） | Jetson 用 `SCHED_FIFO`，抖动 >5 ms 要报警 |
| 平路/坡上限速 | 1.35 / 0.85 m/s | 坡上降速按 `atan` 坡度分段，不是一刀切 |
| 滑移目标 | 0.18 | 草地/松软土实测峰值滑移 0.15–0.22，需现场标定 |
| 速度环 KP/KI | 0.85 / 0.20 | 载荷变化大，KI 抗饱和限幅 ±260 |
| 坡度前馈 | 1.15 × mg sinθ | 前馈不足会“爬-滑振荡”，过多会过驱 |
| 稳定裕度 | 0.75 × atan(track/2h) | 满载 31.9°，超限即限速 |
| 驻车释放条件 | `min(制动, μWcosθ) > 1.15 × Wsinθ` | 15% 余量，不够就拒绝释放 |
| 心跳超时 | 0.6 s | 与遥控链路 50 Hz 匹配 |

## 4. 三个现场标定项（必须做，否则仿真结论搬不过来）

1. **轮径/编码器标定**：直线 20 m 推车计数，反算有效滚动半径（充气胎受压后比名义 0.24 m 小 2–4%），误差直接进滑移率分母。
2. **μ–滑移曲线标定**：在干硬土、松软土、湿滑黏土各做 3 组“低速恒定转矩爬坡”，记录滑移率与 μ 估计，回归出峰值滑移点，替换 `slip_opt=0.18`。
3. **称重与质心标定**：空载/半载/满载三点称重，拟合质心高度；偏载 15% 时验证降速阈值是否触发。

## 5. 失效链（从上到下逐级兜底）

```
Jetson 决策异常 → H7 心跳超时 → 转矩归零 + 弹簧制动（0.6 s 内）
H7 异常     → 驱动器看门狗 → 断使能（驱动器本地 0.2 s）
驱动器异常   → 机械弹簧制动常闭（断电即夹紧）
全部断电    → 弹簧制动保持驻车
```

四级兜底里只有第一级会“丢任务”，后三级都只丢动力不丢制动——这是重载坡地运输最该保住的属性。

## 6. 实机与仿真的已知差距（提前认账）

- 仿真用集总参数轮胎模型，实机松软土会有**压实沉陷**（首次通过 vs 二次通过 μ 不同），所以代码里保留了在线 μ 的慢速修正，而不是完全信先验。
- 相机在逆光/扬尘下深度缺失率会到 20–30%，代价层对缺失区按“上一帧 + 膨胀”处理，宁可保守。
- 摆动桥让四轮接地，但转弯时内外轮速差造成滑移，skid-steer 在松软土上的转向滑移会比仿真大，验收时单独测“原地掉头滑移深度”。
