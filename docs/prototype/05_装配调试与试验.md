# 05 · 装配、调试与试验大纲

## 1. 装配顺序（按“能通电前先能停住”排序）

1. **车架与摆动桥**：铝型材主梁找正（对角线误差 ≤2 mm）→ 装摆动桥铰点 → 装限位块（±12°）→ 手动摆动检查无卡滞。
2. **轮组与制动**：轮毂电机装桥 → 前轮盘刹（含油管排气）→ 后轮电磁失电制动（**断电状态必须夹紧**，先验证再往下）。
3. **电池与电控**：电池仓下挂 → 主回路熔断/总开关/双急停 → DC-DC 与 48→12/5 V 分路 → 绝缘与极性复核。
4. **计算与传感**：Jetson、H7、ESP32 固定 → 相机/LiDAR/IMU/称重安装 → 线束分侧走线（动力线与信号线间距 ≥50 mm）。
5. **货箱与配重**：货箱 4 点称重 → 空载称重归零 → 加载 100/200 kg 砝码验证线性度（误差 ≤2%）。
6. **通电自检**：先断驱动使能，只上逻辑电；确认 CAN 心跳、IMU 双路一致、相机出图、编码器计数正常。

## 2. 标定清单（不做标定就上路，等于拿仿真参数赌）

| 项 | 方法 | 合格判据 |
|---|---|---|
| 水平零位 | 平台调平，双 IMU 静止 60 s | 横滚/俯仰偏差 <0.3° |
| 轮径/里程 | 20 m 直线推车计数 | 里程误差 <1% |
| 称重 | 0/100/200 kg 三点 | 线性误差 <2%，四角偏差 <3% |
| 相机外参 | 棋盘格 + 车身坐标系对齐 | 重投影误差 <0.5 px，地面高程偏差 <2 cm @3 m |
| LiDAR 与相机对齐 | 同一立柱/墙角特征 | 平面残差 <3 cm |
| 滑移曲线 | 三种地面各 3 组恒转矩爬坡 | 峰值滑移点落在 0.15–0.22 |
| 驻车能力 | 18° 坡挂驻车 60 s | 位移 <10 mm，无溜坡 |

## 3. 试验大纲（验收即“能不能下地”的判据）

| # | 试验 | 条件 | 通过判据 |
|---|---|---|---|
| T1 | 满载爬坡 | 20° 松软土，200 kg | 全程通过，平均滑移 <5%，无后溜 |
| T2 | 干硬陡坡 | 25°，200 kg | 通过，电机温度 <85 ℃ |
| T3 | 横坡行驶 | 14° 横坡 + R6 m 弯道 | 不倾翻，侧倾 <25°，限速生效 |
| T4 | 坡道停车再起步 | 18° 松软坡，驻车 60 s | 零溜坡，起步滑移 <8% |
| T5 | 起伏下坡 | 台阶 0.16 m、粗糙度 6 cm | 不托底、不冲坡，制动距离 ≤0.6 m |
| T6 | 湿滑拒行 | 26° 湿滑（μ≈0.45） | 坡脚主动停住并给出拒行原因，P95 滑移 <2% |
| T7 | 失效安全 | 断链、断电、急停、超温各 1 次 | 均在 0.6 s 内停住；急停需人工复位 |
| T8 | 续航 | 满载 20° 往返 1 km | 单次充电 ≥3 趟，SOC 估算误差 <5% |
| T9 | 窄行通过 | 行宽 1.4 m，含 0.3 m 障碍偏置 | 侧向余量 ≥0.1 m，不剐蹭 |
| T10 | 连续作业 | 4 h 循环装卸 | 无过热停机，故障码为 0 |

通过 T1–T7 才允许进果园实采；T8–T10 是作业可用性，可与采收季并行验证。

## 4. 风险与对策

| 风险 | 后果 | 对策 |
|---|---|---|
| 松软土压实沉陷，二次通过 μ 下降 | 同一坡第一次能上、第二次上不去 | 在线 μ 慢修正 + 记忆上次通过点的 μ，二次通过前降速 |
| 相机逆光/扬尘深度缺失 | 代价层空洞，误判可通行 | 缺失区按上一帧保持 + 膨胀；连续 3 帧缺失即降速至 0.5 m/s |
| skid-steer 转向滑移 | 窄行掉头刨坑、损伤根系 | 掉头限速 0.4 m/s；软土优先“三点掉头”而非原地转 |
| 48 V 大电流干扰 IMU | 姿态抖动，误触发急停 | 双 IMU 互校 + 5 Hz 低通 + 动力线屏蔽；本地判据取两路一致值 |
| 电池低温容量衰减 | 早春/秋冬续航不足 30% | BMS 低温限流；SOC <15% 自动返航 |
| 电磁失电制动磨损 | 长期拖滞发热 | 行驶时监测轮温与电流；每月检查间隙 |

## 5. 交付物清单（样机阶段）

- 机械：车架/摆动桥二维图（含公差）、货箱图、装配 BOM（本文 03 章）；
- 电气：原理图（主回路/信号/CAN）、线束表、接插件定义；
- 软件：Jetson 镜像（含本仓库算法）、H7 固件、参数文件、标定记录表；
- 文档：本 5 篇 + GitHub 仓库 + 试验报告模板。

真正卡进度的一般不是算法，而是**轮毂电机与驱动器的匹配、制动与驻车的机械可靠性、以及称重标定**这三件“看起来最简单”的事，排期时给它们留足时间。
