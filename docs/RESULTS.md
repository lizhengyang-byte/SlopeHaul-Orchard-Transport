# 结果与解读

所有数据来自 `python scripts/run_benchmark.py`（seed=1），原始文件：`results/summary.json`、`results/telemetry_*.csv`、`results/comparison.md`、`results/aggregate.json`。

## 1. 汇总

| 指标 | 基线 | 本方案 |
|---|---|---|
| 任务达成（5 场景） | 2/5（S2、S4 到达；S1、S3 失败；S5 停在坡脚但属被动停） | 4/5（S1、S2、S3、S4 到达；S5 主动拒绝） |
| 平均滑移率（五场景均值） | 10.85% | 0.02% |
| 倾翻次数 | 0 | 0 |
| 最大后溜距离 | 5.21 m（S3） | 0.19 m（S5，驻车后） |

## 2. 逐场景

### S1 松软土重载爬坡（18 m，180 kg，坡中 μ≈0.64）

| 指标 | 基线 | 本方案 |
|---|---|---|
| 结论 | 失败（40 s 只到 2.8 m） | 到达（24.2 s） |
| 平均 / P95 滑移 | 9.0% / 50.0% | 0.0% / 0.0% |
| 后溜 | 1.94 m | 0 |
| 能耗 | 1.064 Wh/m | 0.505 Wh/m（−52.5%） |

解读：基线在松软带持续空转，轮子把扭矩耗在滑移上而不是推进，单位里程能耗是本方案的 2.1 倍。这是打滑不只影响安全、也直接吃电的直接证据。

### S2 横坡弯道（14° 横坡，R≈6 m，200 kg）

| 指标 | 基线 | 本方案 |
|---|---|---|
| 结论 | 到达 24.8 s | 到达 15.3 s |
| 最大侧倾 | 14.2° | 14.8° |
| 能耗 | 0.321 Wh/m | 0.294 Wh/m |

解读：两者都没倾翻（侧倾包络 0.75×atan(0.55/0.60) 约为 36°，工作点在 15° 附近，裕度充足）。本方案更快且能耗更低，代价是最大侧倾高 0.6°——因为走得更快、弯道离心力更大。若把侧倾裕度作为硬约束，可再降 0.1 m/s 换回这 0.6°。

### S3 18° 松软坡停车再起步（驻车 8 s）

| 指标 | 基线 | 本方案 |
|---|---|---|
| 结论 | 失败（4.9 s 失控） | 到达 24.5 s |
| 平均滑移 | 43.4% | 0.1% |
| 后溜 | 5.21 m | 0 |
| 能耗 | 5.694 Wh/m | 0.651 Wh/m |

解读：这是差距最大的一组。基线在坡上释放制动后没有驻车能力判断，车体一泻到底；本方案 HOLD 阶段比较制动与静摩擦能力，确认停得住才释放，驻车 8 s 内位移基本为零。

### S4 起伏下坡（−12°，堆石与台阶）

| 指标 | 基线 | 本方案 |
|---|---|---|
| 结论 | 到达 29.2 s | 到达 32.0 s |
| 能耗 | 0.328 Wh/m | 0.336 Wh/m |

解读：本方案在这里反而慢 2.8 s、多耗一点电，这是主动换安全：下坡段按制动距离反推限速，比基线定速低。若只看速度，这是唯一的劣势场景，但差距在噪声级，且倾角与台阶工况下更保守是合理的。

### S5 26° 湿滑坡（物理不可通行）

| 指标 | 基线 | 本方案 |
|---|---|---|
| 结论 | 停在 3.2 m（被动停，不可控） | 停在 4.1 m（主动拒绝） |
| 被阻断栅格占比 | 17% | 72% |
| 后溜 | 1.52 m | 0.19 m |
| P95 滑移 | 16.1% | 0 |

解读：基线靠轮子打滑才停住，车已经在滑；本方案在进入湿滑段前就判定不可通行，提前降速并在坡脚停住，全程无滑移。两者的“停”在时间上差不到 1 m，但可控与不可控是本质区别。

## 3. 与其他指标的对比

- **牵引效率**：S1 基线每米耗 1.064 Wh，本方案 0.505 Wh，降幅过半，来源是滑移减少而非电机更优。
- **估计可信度**：S1 的 μ 估计 MAE 为 0.224，这是本报告最弱的一项。原因：S1 大部分时间工作在滑移 0.09 附近，低于 RLS 的更新窗口下界 0.08 附近，可观测性差。S3 的 MAE 好得多（0.06 量级），因为那里滑移激励充分。这个偏差我们不做掩盖。
- **安全介入**：本方案 S1 为 8 次（限速与降载切换），S2 为 0，S3 为 2（驻车释放），S5 为 4（拒行与停车）。基线几乎为 0，但代价是它根本不知道自己在打滑。

## 4. 可信度与偏差声明

1. 仿真地形为解析函数生成，坡度、粗糙度、台阶幅度都是设定值，不是实测点云；因此“感知准不准”这一环只验证了算法闭环，未验证真实传感器噪声谱。
2. S3 的基线指标被场景下边界截断（否则会一直下滑），读数 5.21 m 是截断值，不是真实滑行距离；这使“差距最大”这一结论偏保守（真实差距更大）。
3. S4 本方案更慢是设计选择（限速保守），不是性能缺陷，但也不能倒过来说“本方案全面占优”。
4. 土壤分类与纹理是合成代理数据，验证集准确率高不代表田间可重复，真实部署必须用实测数据重标定。
5. 所有结果单种子（seed=1）可复现；多种子方差未统计，不能当作统计结论。
